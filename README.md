# Платформа «Шесть»

Одна точка входа для шести тестовых проектов Даниила Девяткина: портал с реестром,
живые стенды приложений, статические лендинги по настоящим путям и работающий
сервис согласования, который эта же страница использует.

```
портал             http://127.0.0.1:8110
стенд «Карточки»   http://127.0.0.1:8200
стенд «Игрушечки»  http://127.0.0.1:3100   (API и WebSocket — :3301)
согласование       http://127.0.0.1:8110/svc/approval/docs
```

## Что внутри

| № | Проект | Как подключён | Адрес |
|---|--------|---------------|-------|
| 01 | Approval Service | вмонтирован в процесс платформы | `/svc/approval` |
| 02 | ДРОП / 001 | статика из репозитория | `/p/drop001/` |
| 03 | Mayhem — Pony Paradise | статика из репозитория | `/p/mayhem/` |
| 04 | Игрушечки | отдельный стенд Next.js + Fastify | `:3100` |
| 05 | Карточки товаров | отдельный стенд FastAPI + React | `:8200` |
| 06 | Катя Усманова | статика из репозитория | `/p/usmanova/` |

Метаданные проектов не написаны руками: `scripts/inventory.py` обходит клоны в
`repos/` и собирает `docs/inventory.json` — количество файлов, строк по языкам,
объём, последний коммит. Портал читает этот файл, поэтому цифры на витрине всегда
совпадают с содержимым репозиториев.

## Быстрый старт

```bash
cd /home/fun/projects/portfolio-platform
cp .env.stands.example .env.stands      # если файла ещё нет
./run.sh                                # всё в одном терминале, логи в logs/
```

Или через systemd (так платформа работает постоянно):

```bash
systemctl --user start portfolio-platform kartochki-stand igrushki-api igrushki-web
systemctl --user status portfolio-platform
```

Проверка живости одной командой:

```bash
curl -s http://127.0.0.1:8110/api/health?force=true | python3 -m json.tool
```

## Структура

```
studio/                 приложение платформы
  main.py               маршруты, health-check, монтирование статики
  catalog.py            чтение реестра из docs/inventory.json
  approval.py           мост к сервису согласования из TestovoeDevyatkin
  templates/            base.html, index.html, project.html
  static/               portal.css, portal.js, шрифты, скриншоты
repos/                  клоны шести репозиториев (не версионируются здесь)
scripts/inventory.py    сборка реестра из репозиториев
tests/                  приёмочные тесты платформы (pytest)
docs/inventory.json     машинный реестр проектов
DESIGN.md               дизайн-система: палитра, шрифты, запреты
ARCHITECTURE.md         решения и их причины
docs/REPORT.md          отчёт о сборке и проверках
```

## Как добавить седьмой проект

1. Склонировать репозиторий в `repos/`.
2. Добавить запись в `META` внутри `scripts/inventory.py` (slug, номер, название,
   бриф, роль, акцент, адрес) и перезапустить скрипт.
3. Если проект статический — положить его путь в `STATIC_PROJECTS`
   (`studio/config.py`). Если нужен собственный сервер — в `STAND_PROJECTS`
   и отдельный systemd-юнит.
4. Снять скриншот в `studio/static/shots/<slug>.jpg` — он появится в реестре.

## Ограничения, о которых честно

- Стенды приложений открываются на своих портах: Next.js и React-SPA собираются
  с абсолютными путями к ассетам, и перенос под общий префикс потребовал бы правок
  в их сборке. Портал встраивает стенд в страницу проекта через iframe, а кнопка
  «Открыть стенд» ведёт на прямой адрес.
- Публикация наружу не настроена намеренно: платформа слушает локальную сеть.
- База согласования — SQLite в `data/approval.db`; для настоящей нагрузки сервис
  переключается на Postgres переменной `DATABASE_URL` без правок кода.
