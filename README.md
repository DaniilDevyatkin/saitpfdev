## Быстрый старт

```bash
cd /home/fun/projects/portfolio-platform
cp .env.stands.example .env.stands      # если файла ещё нет
./run.sh                                # всё в одном терминале, логи в logs/
```

Или через systemd (так витрина работает постоянно):

```bash
systemctl --user start portfolio-platform kartochki-stand igrushki-api igrushki-web \
                      mongo-local maison-stand tattoo-stand
systemctl --user status portfolio-platform
```

Стендам Maison и TatuSait нужна MongoDB. В системе стоит **4.4** — последняя ветка
без требования AVX (виртуальный CPU QEMU его не отдаёт), запускается юнитом
`mongo-local` с локальной копией `libssl1.1` в `/home/fun/local/mongo`.

Проверка живости одной командой:

```bash
curl -s http://127.0.0.1:8110/api/health?force=true | python3 -m json.tool
```

## Как добавить седьмой проект

1. Склонировать репозиторий в `repos/`.
2. Добавить запись в `META` внутри `scripts/inventory.py` (slug, номер, название,
   бриф, роль, акцент, адрес) и перезапустить скрипт.
3. Если проект статический — положить его путь в `STATIC_PROJECTS`
   (`studio/config.py`). Если нужен собственный сервер — в `STAND_PROJECTS`
   и отдельный systemd-юнит.
4. Снять скриншот в `studio/static/shots/<slug>.jpg` — он появится в реестре.

## Ограничения, о которых честно

- Стенды приложений открываются на своих портах: Next.js и React-SPA собираются
  с абсолютными путями к ассетам, и перенос под общий префикс потребовал бы правок
  в их сборке. Витрина встраивает стенд в страницу работы через iframe, а кнопка
  «Открыть стенд» ведёт на прямой адрес.
- Четыре раздела «Карточек товаров» — один стенд и четыре записи: у SPA hash-роутинг,
  поэтому запись ведёт на `#/ldlatte` и соседние разделы открываются тем же стендом.
  Цифры в карточке раздела считаются по репозиторию целиком — это подписано на странице.
- MongoDB намеренно 4.4: ветки 5.0+ требуют AVX, которого у виртуального CPU нет.
- Публикация наружу не настроена намеренно: витрина слушает локальную сеть.
- База согласования — SQLite в `data/approval.db`; для настоящей нагрузки сервис
  переключается на Postgres переменной `DATABASE_URL` без правок кода.
