# Дизайн-система: платформа «Шесть» — портфолио Даниила Девяткина

## 0. Установки

VARIANCE: 7 | MOTION: 4 | DENSITY: 5

Плотность средняя: витрина читается как технический паспорт, а не как галерея.
Вариативность высокая: центральный герой-блок запрещён, вся страница построена
на асимметричной сетке «реестр слева — превью справа».

## 1. Атмосфера

Светлый бумажный фон, тяжёлая чёрная типографика, тонкие волосяные линейки.
Ощущение инженерного журнала: записи пронумерованы, у каждой есть бриф и ответ.
Цвет вводится точечно — по одному акценту на проект, как ярлык на корешке папки.

## 1b. Сигнатурный элемент (обязателен, ровно один)

**Реестр проектов** — шесть полноширинных строк-записей, где слева огромный номер
(01–06) и название, а справа по наведению проявляется живое превью проекта.
Это не карточки и не сетка: строка ведёт себя как запись в гроссбухе — она
раскрывается по вертикали, соседние строки притухают, превью приезжает справа.
Живёт в слое взаимодействия + типографики, повторяется на главной и в списке
проектов, поэтому читается как язык платформы, а не как эффект.

## 2. Палитра и роли

- **Бумага** (#F2EFE9) — фон платформы, основной слой.
- **Чернила** (#12141A) — текст, линейки, крупные номера.
- **Тихий** (#6B6F76) — метаданные, подписи, единицы измерения.
- **Волосяная линейка** (#D5CFC3) — разделители строк реестра.
- **Акцент платформы** (#0540F2) — ссылки, фокус, кнопка действия, статус «живой».
- **Акценты проектов** — по одному на проект: #0540F2, #C8553D, #8FBF12, #7B61FF,
  #0F8B8D, #C05A78. Только для чипа проекта и тонкой полосы слева от записи.

Запрещено: чистый #000, неоновые градиенты, фиолетовое свечение, больше одного
акцента в блоке.

## 3. Типографика

- Display: **Unbounded** (кириллица, характерные широкие формы) — названия проектов,
  заголовки секций, номера. Трекинг −0.02em, иерархия весом и цветом.
- Body: **Golos Text** — текст, описания, таблицы. Максимум 68 символов в строке.
- Mono: **JetBrains Mono** — цифры, метрики, код, пути, статусы.
- Запрещено: Inter, системные серифы, текст-градиент в заголовках.

Шрифты лежат локально в `studio/static/fonts` (woff2, подмножество latin+cyrillic),
внешние CDN не используются — платформа обязана рисоваться без интернета.

## 4. Компоненты

- **Кнопки**: прямоугольные, 2px радиус, `:active` сдвигает на 1px вниз. Без свечения.
  Основная — синяя с белым текстом, вторичная — контурная.
- **Строка реестра**: `border-top: 1px` линейкой, высота ≥ 120 px, hover поднимает
  фон до #FFFFFF и проявляет превью; вне hover соседи притухают до 55% прозрачности.
- **Чипы**: моноширинные, 0.75rem, uppercase, рамка 1px, без заливки (кроме акцента проекта).
- **Таблица статуса**: настоящие `<table>`, mono-цифры, зелёный/красный только для состояния.
- **Формы согласования**: подпись сверху, подсказка под полем, ошибка снизу, фокус-кольцо
  цветом акцента. Никаких плавающих подписей.
- **Пустые состояния**: показывают, как заполнить данные (пример запроса), а не «нет данных».

## 5. Раскладка

- Контейнер `max-width: 1560px`, боковые поля `clamp(16px, 4vw, 56px)`, ширина заполняется.
- Реестр — CSS Grid `grid-template-columns: 120px 1fr 320px`, схлопывается в одну колонку
  на 900 px, ниже 600 px номер уходит в строку с названием.
- Секции — полноширинные полосы с собственным фоном (бумага / чернила / тон проекта).
- Полная высота — `min-height: 100dvh`, никогда `100vh`.
- Горизонтального скролла нет ни на одной ширине.

## 6. Движение

Тир — CSS-анимации, без библиотек. Только `transform` и `opacity`.
Появление строк — каскад через `animation-delay` (60 мс на шаг), контент виден
по умолчанию без JS. Всё под `prefers-reduced-motion: reduce`.

## 7. Запреты (BANNED)

- Никаких эмодзи в интерфейсе.
- Никаких трёх одинаковых карточек в ряд — только строки реестра.
- Никаких «Elevate / Seamless / Unleash» — только конкретные глаголы.
- Никаких выдуманных круглых цифр — метрики берутся из репозиториев.
- Никаких стоковых аватаров и «John Doe» — автор подписан именем.
- Никаких кастомных курсоров, свечений, glassmorphism, параллакса.
