## Что сломалось по дороге и как починено

1. **Два репозитория не клонировались по HTTPS** — приватные. Перешёл на SSH-ключ
   `~/.ssh/id_ed25519_github`, который уже был настроен в системе.
2. **`TestovoeKartochki` (349 МБ) не успел склонироваться** за отведённые
   300 секунд — клонирование ушло в фон и завершилось.
3. **`better-sqlite3` не собирался.** Сначала npm заблокировал install-скрипты,
   потом выяснилось, что в системе нет `make`/`g++`, а под Node 26 у модуля нет
   готового бинарника. Решение: распаковал Node 22 LTS в `/home/fun/local/node22`
   без root и пересобрал зависимости под него — прекомпилированный бинарник
   встал сразу.
4. **Стенд «Игрушечек» падал при старте** на поиске миграций: код ищет
   `src/db/migrations` относительно `process.cwd()`. Запуск перенесён в каталог
   `server/`, где миграции и лежат.
5. **`.env` с `JWT_SECRET` ломал сервис согласования** — его pydantic-настройки
   читают `.env` из рабочего каталога и падают на лишнем поле. Файл переименован
   в `.env.stands`, юнит указывает на него явно.
6. **Мобильная вёрстка давала горизонтальный скролл 68 px** — виновата таблица
   статуса. На узких экранах скрыты служебные колонки, скролл стал нулевым
   (проверено в браузере: `scrollWidth - clientWidth === 0`).
7. **Параллельно стартовавшие kanban-воркеры** успели создать вторую реализацию
   платформы в том же каталоге. Дубли удалены, оставлена одна рабочая ветка
   (`studio/`), из чужого черновика ничего не тащил — своя реализация уже была
   проверена вживую.

## Исправление: стенд «Игрушечек» падал по сетевому адресу (19.11.2026, 08:05)

Симптом: страница работы открывалась, а внутри рамки вместо игры — «Экран не
загрузился. Мы уже записали техническую информацию».

Диагностика: по `127.0.0.1:3100` приложение работало, по `192.168.51.81:3100` —
падало. Перехват `console.error` до загрузки дал точную ошибку:
`TypeError: Cannot read properties of undefined (reading 'addEventListener')`
в `ServiceWorkerRegistrar`.

Причина: в компоненте два `useEffect`. Первый проверяет
`"serviceWorker" in navigator`, второй — нет. Service Worker доступен только
в защищённом контексте (HTTPS или localhost), поэтому по обычному `http://`
на сетевом адресе `navigator.serviceWorker` равен `undefined`, и второй эффект
ронял рендер — срабатывал error boundary.

Исправление — одна строка-гард во втором `useEffect` (правка в самом репозитории
`Igrushki`, не в платформе): `if (!("serviceWorker" in navigator)) return;`.
Приложение пересобрано, стенд перезапущен, по LAN-адресу открывается форма входа.
